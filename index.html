문제집 관리

단어 뜻 등록

문제 화면의 "📖 단어 뜻 보기"에 표시할 뜻이에요. 한 줄에 단어 하나씩, 단어와 뜻을 탭·콜론·2칸 이상 공백 중 아무 것으로 구분해서 붙여넣으세요. 뜻이 여러 개면 세미콜론(;)으로 나누면 번호가 붙어 표시됩니다.
.txt 파일 업로드
또는 직접 붙여넣기
뜻이 없는 단어 목록 뽑기
아직 뜻이 없는 영단어만 추려냅니다. 이 목록을 넘겨서 단어: 뜻 형식으로 받아온 뒤, 위쪽 "직접 붙여넣기"에 넣으면 됩니다.
자동으로 채우기 (번역 API)
뜻이 없는 단어를 MyMemory 무료 번역 API로 한 번에 받아옵니다. 가입도 API 키도 필요 없어요. 받아온 뜻은 기기에 저장되므로 문제를 풀 때는 인터넷을 쓰지 않습니다. 기계 번역이라 사전처럼 정확하진 않으니, 중요한 단어는 위에서 직접 덮어써주세요.
이메일을 넣으면 하루 한도가 5,000자에서 50,000자로 늘어납니다. 어디에도 전송되지 않고 API 요청에만 함께 보냅니다.

문제집 공유하기

지금 가진 문제집을 그대로 담은 새 HTML 파일을 만듭니다. 이 파일을 웹에 올리면 링크를 받은 사람은 아무것도 올리지 않고 바로 문제를 풀 수 있어요. 각자의 정답·별표 기록은 각자 기기에만 남습니다.
받은 파일을 app.netlify.com/drop에 끌어다 놓으면 바로 링크가 만들어져요. 자세한 방법은 README를 참고하세요.
